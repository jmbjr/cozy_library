How to Mod Cozy Library

A pack is a swappable bundle of content and presentation. Copy an existing file in packs/, give it a new id, and register it on the start page. The engine should not need changing.

Asset categories

View

Preset: Default View

Controls viewport width/height, the initial haze character, and progress messages. Edit view in the pack.

Bookshelf

Preset: Default Bookshelf

Controls columns and slot height. Shelf capacity is selected by the player at game start. Edit shelf.

Book appearance

Preset: Default Book Style

Controls spine, spine-text, and offer colors through bookStyle. Individual visual variants can be added later without changing book knowledge.

Books

Presets: every book in the selected pack.

Each entry has id, title, text, and semantic facts[]. Books deliberately contain no image paths.

World objects

Preset: Default World Object mapping

worldObjects[] maps a semantic fact to something visible. Current content is emoji/text; this is the seam where PNGs, sprites, or animation references will go.
