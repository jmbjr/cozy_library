How to Mod Cozy Library

Assets and bundles are different things. Asset types are independently selectable. A bundle is only a convenience manifest that names a compatible collection of assets.

Asset categories

View

Single-select presentation asset.

Current options

  • Default View

Bookshelf

Single-select layout asset; capacity remains a separate game setting.

Current options

  • Default Bookshelf — 6-column compact shelf
  • Wide Oak Bookshelf — 4-column shelf with taller books

Book appearance

Single-select presentation asset.

Current options

  • Default Book Style

Books

Multi-select content assets. Books emit semantic facts and may declare required world-object sets.

Current options

  • Starter Valley Books
  • Tidepool Books

World objects

Multi-select visual assets. Object sets may be enabled without books; unused objects simply never appear yet.

Current options

  • Starter Valley Objects
  • Expanded Valley — extends Starter Valley with weighted graphic variants
  • Tidepool Objects

Graphic variants

A world object may define graphics[] instead of one content value. Each graphic has a relative weight. For example, weights 6, 3, and 1 produce roughly 60%, 30%, and 10% selection. A graphic is selected when the object first appears and remains stable for that playthrough. Conditional variants can have their own weighted graphics.

{"fact":"creature:mail_snail","graphics":[{"content":"🐌✉️","weight":6},{"content":"🐌📨","weight":3},{"content":"🐌📦","weight":1}]}

Expanded Valley is the first example asset. It extends Starter Valley Objects and replaces several objects with weighted graphic variants.

Dependencies

A book set can declare requiresWorldSets. Start Game validates those dependencies. This is intentionally coarse-grained v1 dependency handling; later we can validate individual facts/object capabilities and procedural variants.

Bundles

Starter Valley Bundle and Tidepool Bundle are convenience presets. Applying one selects its listed assets. Bundles do not own or duplicate the assets.

Source of truth

The current registry is assets/catalog.js. It contains separate registries for views, shelves, bookStyles, bookSets, worldSets, and bundles.
