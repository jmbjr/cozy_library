How to Mod Cozy Library

Assets and bundles are different things. Asset types are independently selectable. A bundle is only a convenience manifest that names a compatible collection of assets.

Asset categories

Graphic variants

A world object may define graphics[] instead of one content value. Each graphic has a relative weight. A graphic is selected when the object first appears and remains stable for that playthrough.

{"fact":"creature:mail_snail","graphics":[{"content":"🐌✉️","weight":6},{"content":"🐌📨","weight":3},{"content":"🐌📦","weight":1}]}

Book appearance overrides

Books normally inherit the selected Book appearance asset. An individual book may optionally define appearance to override any subset of the resolved style, such as spine, text, offer, height, width, or lean. Unspecified values continue to come from the selected Book Style.

{"id":"special-book","title":"A Particularly Blue Volume","appearance":{"spine":"#3f5673","offer":"#536f91"}}

Dependencies

A book set can declare requiresWorldSets. Start Game validates those dependencies. This is intentionally coarse-grained v1 dependency handling; later we can validate individual facts/object capabilities and procedural variants.
